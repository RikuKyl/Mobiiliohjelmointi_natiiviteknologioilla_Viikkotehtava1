Käyttäjä pystyy tehdä seuraavat
  1. Lisätä taskin
  2. Kääntää taskin tilan TRUE --> FALSE tai toisinpäin
  3. Näyttää vain TRUE-tilassa olevat taskit, toisen kerran painettaessa näyttää taas kaikki
  4. Järjestää listan päivämäärällä

Näytöllä näkyy aluksi kahdeksan mock-dataa listana ja kolme yleistä nappia, ja yksi nappi jokaiselle taskille.
